# House rules: keep Janelle's memory and boards current

Janelle owns these businesses. Start every reply with "Janelle". Use short, step-by-step bullets.
Nothing is published and no money is spent without Janelle's yes. Work must score 9.5/10 before it goes to her.

**This repo's business folder:** Google Drive > My Drive > Janelle HQ > `Projects`

## 1. At the START of every session (before any work)

Use the Google Drive connector to read these, so you never redo or re-ask something already done:
1. `Janelle HQ/Projects/TASKS.md`: the board (what's done, in progress, waiting on Janelle).
2. `Janelle HQ/Projects/MEMORY.md`: lasting facts for this business (prices, accounts, what's live, decisions).
3. `Janelle HQ/HANDOFF.md`: the "Next up" table, to see who picks up what.

If `TASKS.md` or `MEMORY.md` is missing from the folder, create it now from the starter layout below.

## 2. Before you FINISH any session that changed something

1. **Board.** Update `Projects/TASKS.md`. Drive can't edit a file in place, so read the current file,
   create the new `TASKS.md` in the same folder, then trash the old one.
   - Keep the four sections: 🔴 Needs Janelle · 🟡 In progress · ⚪ Backlog · ✅ Done (last 10).
   - Traffic lights: red = urgent, orange = next, green = soon.
   - Update the `_Updated:_` line with the date and "Claude Code".
   - Never delete or reword an item you didn't create. Finished items move to ✅ Done with one evidence line.
2. **Memory.** Add any lasting fact to `Projects/MEMORY.md` the same way (dated bullet; never secrets).
3. **Master list.** If something now waits on Janelle, add it to `Janelle HQ/TASKS.md` > 🔴 Needs Janelle.
   When it's done, move it to ✅ Done there too.
4. **Handoff.** Add one dated line to the Log in `Janelle HQ/HANDOFF.md` and update this business's "Next up" row.
5. **Files.** Save deliverables to `Janelle HQ/Projects/`. OneDrive is backup only.
6. **Secrets.** Never put API keys or passwords in any .md file, repo, or chat.

A nightly board keeper (about 9pm Sydney) also sweeps the day's Claude Code and Cowork sessions,
but don't rely on it: update the board and memory yourself before you stop.
